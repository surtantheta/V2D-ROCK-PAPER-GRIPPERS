# V2D Track 1: main v2.1 and shared-scale/contact alternative

Frozen source snapshot prepared for two existing 30-episode reconstructions.
`code/` includes main S1–S7 and the test adapter `branch_fit_episode.py`.
`experiments/offline_opt_20261020/code/` includes all frozen optimization dependencies.
`SOURCE_MANIFEST.json` records the exact copied source hashes and original paths.
`provenance/` records per-episode assembly and fit diagnostics.

The historical runners use `/home/tanuj/V2D_challenge` and external model/environment
paths. Reproduce at that root (or configure equivalent mounts); use the official
submission kit, the released Track 1 videos, and the externally licensed model
checkpoints listed in `code/README.md`. The frozen source contains no test GT,
videos, model checkpoints or prediction archives. This is a source snapshot,
not a self-contained model distribution. Third-party licenses remain applicable.

Main inputs: `work/submission_v2` generated by S1–S7 and v2.1 repair.
Optimization adapter: `python code/branch_fit_episode.py --episode N` for N=0..29,
using main raw S6 translation, MetaV3RSE/depth-scale observations and fixed v2.1
rotation; package the `work/branchfit/shared_scale_contact` output. Preserve its
stored positive `object_scale` and original mesh origin.

For packaging, URL replacement, offline validation and submission commands see
`upload_preparation/README.md` in the original workspace. Both files share their
human, mesh and rotations; neither has an official score. The alternative is not
the separate MoGe-based development pipeline and is not claimed to win.
